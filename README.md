# DIY Project Planner

Concept demo: a customer picks a project (deck, fence, interior repaint, shelving), enters dimensions, and gets a complete bill of materials with quantities, organized the way the build runs — with safety and permit prompts built in.

**Try it:** https://rahuldara-a11y.github.io/diy-project-planner/

Single-file HTML, no build step, no dependencies. Sample pricing shown for demonstration.
